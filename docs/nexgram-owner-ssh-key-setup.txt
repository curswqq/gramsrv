СОЗДАНИЕ SSH-КЛЮЧА ДЛЯ ДОСТУПА К СЕРВЕРУ NEXGRAM
================================================

Инструкция для Windows 10/11.


1. ОТКРОЙТЕ POWERSHELL
----------------------

Откройте обычный PowerShell от своего пользователя.
Запуск от имени администратора не требуется.


2. СОЗДАЙТЕ ПАПКУ ДЛЯ SSH-КЛЮЧЕЙ
--------------------------------

Выполните команду:

New-Item -ItemType Directory -Force "$env:USERPROFILE\.ssh" | Out-Null


3. СОЗДАЙТЕ ОТДЕЛЬНЫЙ КЛЮЧ NEXGRAM
----------------------------------

Скопируйте и выполните команду целиком:

ssh-keygen `
  -t ed25519 `
  -a 100 `
  -C "nexgram-owner" `
  -f "$env:USERPROFILE\.ssh\nexgram_owner_ed25519"


4. УСТАНОВИТЕ ПАРОЛЬНУЮ ФРАЗУ
-----------------------------

После запуска появится запрос:

Enter passphrase (empty for no passphrase):

Рекомендуется придумать надёжную парольную фразу и сохранить её в менеджере
паролей. При вводе символы не отображаются — это нормально.

Затем PowerShell попросит повторить парольную фразу:

Enter same passphrase again:

Парольную фразу нельзя забывать: без неё приватный ключ использовать не
получится.


5. ПРОВЕРЬТЕ СОЗДАННЫЕ ФАЙЛЫ
----------------------------

После успешной генерации появятся два файла:

C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\.ssh\nexgram_owner_ed25519
C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\.ssh\nexgram_owner_ed25519.pub

Назначение файлов:

- nexgram_owner_ed25519 — приватный ключ. Никому не отправлять.
- nexgram_owner_ed25519.pub — публичный ключ. Его нужно передать
  администратору сервера.


6. ВЫВЕДИТЕ ПУБЛИЧНЫЙ КЛЮЧ
--------------------------

Выполните:

Get-Content "$env:USERPROFILE\.ssh\nexgram_owner_ed25519.pub"

PowerShell выведет одну строку примерно следующего вида:

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA... nexgram-owner

Скопируйте всю строку целиком, включая начало ssh-ed25519 и комментарий
nexgram-owner в конце.


7. ЧТО НУЖНО ПЕРЕДАТЬ АДМИНИСТРАТОРУ
------------------------------------

Передайте администратору только один из следующих вариантов:

- всю строку, полученную командой Get-Content;
- файл nexgram_owner_ed25519.pub.

Никогда не отправляйте файл nexgram_owner_ed25519 без расширения .pub.
Это приватный ключ, который предоставляет полный доступ от вашего имени.

После получения публичного ключа администратор добавит его на сервер и
пришлёт отдельную инструкцию для подключения через PowerShell, Git Bash и
WinSCP.
